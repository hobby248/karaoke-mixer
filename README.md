# K 歌混音台

Windows 桌面 K 歌混音工具。將麥克風與 YouTube／瀏覽器伴奏或本機歌曲混合，透過 VB-CABLE 送入 Discord。

作者：阿Q x Codex。聯絡方式：Discord id:quebecliec。

## 功能

- 繁體中文、简体中文、English；淺色、深色、跟隨 Windows 主題。
- 麥克風、伴奏與混音輸出獨立音量、靜音，人聲回音、電平表及耳機監聽；麥克風可另加0～+20dB，人聲專用限幅不壓低伴奏。
- 獨立伴奏視窗：YouTube 搜尋、一般 HTTPS 網址、影片原有歌詞或字幕、置頂與全螢幕。網站相容性依各站播放器及限制而定。
- 外部瀏覽器音訊，或本機 MP4、MP3、WAV、M4A 等 Windows 可解碼媒體；本機影片可開啟畫面跟唱。
- 本機伴奏支援 ±12 半音升降 Key；內建瀏覽器提供升降 Key 相容模式，需耳機並依網站實測。外部瀏覽器不支援升降 Key。
- 雙軌 WAV 錄音：混音與乾麥克風分開保存，不自動上傳。
- 同區網手機遙控：QR Code 或網址加八位數配對碼，可調音量、靜音、回音、Key、監聽、語言與主題，以及本機播放與錄音。網站播放器仍在電腦操作。
- 可選擇正式／測試更新頻道及啟動檢查；更新會備份並驗證，不在混音或錄音時安裝。
- 程式內客服對話、歷史與未讀回覆，音檔／截圖需另外選取並確認上傳；自願匿名統計預設關閉。
- 隨附 VB-CABLE 官方標準版原始安裝包與安裝引導；內含 .NET 8／WPF／ASP.NET Core 執行環境。

## 第一次使用

建議 Windows 11 x64；Windows 10（含22H2／LTSC）只顯示相容性提醒，可繼續啟動。各功能仍依系統與驅動能力判斷。內建伴奏視窗需要網路與 Microsoft WebView2 Runtime；缺少 Runtime 時，程式會提供官方安裝連結。

1. 解壓縮並啟動程式，閱讀使用條款。若沒有 VB-CABLE，按「安裝音訊驅動」。
2. 按「啟動 VB-CABLE 官方安裝程式」，同意 Windows 權限提示，在官方視窗按「Install Driver」。完成後儲存工作並自行重新啟動電腦，再回程式「重新偵測」。
3. 「我的麥克風」選實體麥克風；「Discord 混音輸出」選 **CABLE Input**；耳機監聽選耳機。
4. Discord 桌面版輸入選 **CABLE Output**，輸出選耳機。請戴耳機，避免喇叭回授。
5. 選擇伴奏來源並按「開始混音」。本機歌曲另按「播放」。

Discord 可先關閉噪音抑制、回音消除與自動增益，再依試聽結果調整，避免伴奏被消除。分享畫面時避免重複分享同一份伴奏音訊。

外部瀏覽器模式可能擷取同程序其他分頁的音訊，建議使用專門播放伴奏的瀏覽器，Discord 使用桌面版。

## 人聲與伴奏同時斷音

先展開程式主視窗的「Discord 設定與使用說明」，可依介面語言閱讀繁體中文、简体中文或 English 指引。

若只有 Discord 聽眾聽到斷音，請一次只改一項，使用相同伴奏及說話方式比較；沒改善就還原原設定。

1. 確認 Discord 輸入裝置為 **CABLE Output**。若有「音訊子系統」，將標準（Standard）改為傳統（Legacy），依提示重新啟動 Discord 再測試；找不到此選項可略過。[Discord 官方排查說明](https://support.discord.com/hc/en-us/articles/31623498041623-Discord-Troubleshooting-Guide)
2. 若仍斷音，另外測試「按鍵發話」，全程按住按鍵，檢查是否與自動輸入靈敏度門檻有關。[Discord 語音輸入模式](https://support.discord.com/hc/en-us/articles/211376518-Voice-Input-Modes-101-Push-to-Talk-Voice-Activated)
3. 混音且 Discord 已連線時開啟 VB-CABLE 控制面板，觀察 **Push loss／Pull loss** 是否持續增加。先記錄輸入、輸出、Internal SR 與 Max Latency；保留目前取樣率，不直接套用他人的緩衝數值。[VB-CABLE 手冊](https://vb-audio.com/Cable/VBCABLE_ReferenceManual.pdf)
4. 用雙軌錄音持續說話並播放伴奏約 30 秒，記下聽眾聽到斷音的時間，再透過問題回報主動附上 `-mix.wav`、`-mic.wav` 及控制面板截圖。錄音正常仍不能完全排除程式輸出、VB-CABLE 或 Discord 問題。

這些是排查方法，不保證解決所有斷音。本程式不會自動調整 Discord、VB-CABLE 或 Windows 音訊設定；附件需另外選檔並確認上傳。

## 手機遙控

電腦與手機連到相同區網；電腦可接有線網路。在電腦「手機遙控」選擇私人網路介面並啟用，再用手機掃 QR Code，或輸入畫面網址與配對碼。配對碼有效兩分鐘且限用一次，可重新產生或撤銷授權。音訊需先在電腦啟動。

手機頁面使用未加密 HTTP，只在可信任私人區網使用；不支援跨網路，不需將路由器連接埠公開。Windows 防火牆許可依實際環境僅允許私人網路。遙控預設關閉；關閉遙控視窗不會停止服務，需按停用或關閉程式。手機斷線不停止電腦混音及錄音。

## 資料與限制

設定、身份憑證、客服草稿、備份與伴奏網站資料位於 `%LOCALAPPDATA%\KaraokeMixer`；錄音保存在你選擇的資料夾。更新只替換程式清單內的檔案。使用統計預設關閉，手動回報需另行同意；完整條款與隱私告知可在程式內閱讀。

程式不會自動開啟麥克風、安裝驅動、重新啟動電腦或修改 Windows／Discord 預設音訊設定。不提供 AI 去人聲、YouTube 下載、純音訊自動產生歌詞、歌單或 MP3 錄音匯出。網站廣告、登入、驗證及內容限制由網站處理。
